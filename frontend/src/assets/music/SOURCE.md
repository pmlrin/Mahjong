# 牌桌音乐来源

## 「雪夜灯下的小魔术」：`table-theme.m4a`

项目负责人提供的成品曲，2026-11-20 交付，原文件为 `雪夜灯下的小魔术.mp3`（MP3，48 kHz 立体声，约 185 kbps，154.0 秒，SHA-256 `9ece8d87d8feb92f8c98f83ba7fc7fa4bf8fe2434e1402765859467be8b061ce`）。项目负责人请人按本项目文案方向（雪夜、灯、一点小魔术）制作的委托作品。据项目负责人确认（2026-11-20），作者允许本项目商用，包括在公开网站上播放。

### 从原文件到循环

原曲开头直接进入、没有淡入，结尾在约 151 秒处的最后一个和弦后余音渐弱。首尾和声一致：开头 3 秒与结尾余音的音级分布相关系数为 0.90，都在降 B 小调／降 G 大调一带。脉搏约 82 拍，每拍 0.73 秒。处理步骤如下：

1. 用 macOS `afconvert -f WAVE -d LEI16` 把 MP3 解码成 WAV。解码长度为 7,392,000 帧，编码延迟已去掉。
2. 循环长度取 151.43 秒。最后两个音落在 150.43 秒和 150.80 秒，开头第一个音在 0.10 秒，这样曲子重新开始的那一下正好落在最后一个音之后一拍。
3. 151.43 秒之后剩下的 2.57 秒余音叠加到开头，余音最后 0.3 秒线性淡出。开头加 20 毫秒淡入，因为原文件第一个采样不在零点。其余内容未改，也没有调整音量（峰值 0.57）。
4. 用 `afconvert -f m4af -d aac -b 192000` 编码。结果为 7,268,640 帧有效，48 kHz，3.6 MB，SHA-256 `92ca27e2baa2c0e8fb8d5fdab5e7872c3da91896999ee5d3a15798994131eba0`。

实测：在 Chrome 中解码后时长为 151.430 秒；首尾相接处的跳变为 0.0099，小于平常相邻采样的变化（0.0109），没有爆音。接缝前后各 1.5 秒内每 0.1 秒测一次响度，只有最后一个和弦后约 0.3 秒低 4 dB 左右，那是乐句之间的换气，不是空白。

用途（`frontend/src/music.ts`）：牌桌音乐开启时循环播放，按平均响度（RMS）统一到 0.022。
