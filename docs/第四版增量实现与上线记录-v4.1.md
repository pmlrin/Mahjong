# 第四版增量实现与上线记录 v4.1

2026-11-02，版本0.4.1、实时协议2.0。已更新[正式站](https://mahjong.yangjm.cn/)与[隔离预览](https://mahjong.yangjm.cn/preview/)，沿用用户此前直接部署到现有阿里云服务器的授权。

## 使用入口

- 正式账号登录后，进入“个人与账号 → 上传个人头像”，选择 PNG／JPEG／WebP，调整缩放和位置，再保存。原图限5MB、1600万像素，实际发送256×256 PNG。修改头像不消耗改名次数；等待厅或对局占位须先自行处理。游客继续使用默认头像。
- “玩法说明”先展示六条简明规则和基本和牌图示；“查看全部42种役种与示例牌”展开本桌完整役种，每项有番数、条件、门清／副露要求及完整手牌。可搜索并恢复全部；牌组在窄屏自动换行。
- 流局满贯以弃牌河另示，宝牌不当作役；不支持的人和与地方役明确说明。计分规则未变。

完整接口、图片限制、存储与清理策略见[功能说明](第四版增量功能-v4.1.md)。
