# 一桌 · 完整规则

四人立直麻将 · 东风／半庄 · 固定规则

## 1. 文档约定与适用范围

所有真人与 AI 使用同一套规则。

本项目采用四人立直麻将，支持东风战和半庄战，首版默认开放东风战。使用赤宝牌，允许食断与后付。规则中存在平台差异的项目均在本文明确选定，房间开始后不可临时变更。

本文不是 WRC、EMA、雀魂或天凤规则的逐条复刻，也不宣称与任一平台完全兼容。参考资料用于核对术语与边界，发生差异时，以本项目明确写出的规则为准。

### 1.1 核心配置一览

| 项目 | 本项目规则 |
| --- | --- |
| 人数 | 固定四个座位，真人与 AI 可混合 |
| 默认赛制 | 东风战；房主可在牌桌改为半庄战 |
| 起始点数 | 每人 25,000 点 |
| 目标点数 | 30,000 点，用于正常终局及延长判断 |
| 食断、后付 | 均允许 |
| 赤宝牌 | 赤五万、赤五筒、赤五索各一张 |
| 一番缚 | 必须至少有一个役；宝牌不能代替役 |
| 双响 | 允许；两家分别收取和牌点与本场 |
| 三家和 | 途中流局，不结算三份荣和 |
| 形式听牌 | 承认；无役听牌、振听听牌可参与流局听牌结算 |
| 荒牌连庄 | 庄家听牌连庄，未听换庄 |
| 和牌连庄 | 和牌者包含庄家时连庄 |
| 和了止、听牌止 | 最后计划局中庄家达到目标且排名第一时自动终局 |
| 飞人 | 单局全部结算后，有人小于 0 点则终局；恰好 0 点不飞 |
| 延长 | 东风战最多延长至南四局，半庄战最多延长至西四局 |
| 切上满贯 | 不采用；4 番 30 符、3 番 60 符仍为 7,700／11,600 点 |
| 累计役满 | 采用；普通役与宝牌合计 13 番起按一倍役满封顶 |
| 双倍役满变体 | 不采用；国士十三面、四暗刻单骑、大四喜、纯正九莲均各一倍 |
| 多役满复合 | 采用；不同役满可叠加 |
| 责任支付（包牌） | 仅大三元、大四喜适用；四杠子不设包牌 |
| 流局满贯 | 采用，详见第 12 节 |
| 人和、地方役 | 不采用 |
| 马点、头名赏 | 首版不采用，仅记录最终点数、净得失和名次 |
| 同点排序 | 按本场比赛开局时的东、南、西、北顺序优先 |

### 1.2 术语

- **一局**：从一次配牌开始，到和牌、荒牌或途中流局结束。
- **一场**：完整的东风战或半庄战，包含连庄和必要的延长局。
- **场风**：本圈对应的风，东场为东，南场为南，西场为西。
- **自风**：本局玩家对应的东、南、西、北。东家是庄家，其余为子家。
- **门清**：没有吃、碰、明杠、加杠；暗杠不破坏门清，荣和本身也不破坏门清。
- **副露**：公开的吃、碰、明杠、加杠。本文涉及“所有已声明面子”时，会明确包含暗杠。
- **幺九牌**：一、九数牌及全部字牌。**中张牌**：二至八数牌。
- **面子**：顺子、刻子或杠子。**雀头**：两张同种牌。
- **上家／下家／对家**：依固定座位和逆时针行牌方向确定，不随屏幕旋转变化。

## 2. 麻将牌、座位与公开信息

### 2.1 牌组

全套 136 张牌，34 种牌各四张：万、筒、索各一至九，风牌东南西北，三元牌白发中。没有花牌、百搭牌或北拔宝牌。

每种五的四张中，有且只有一张为赤五，另外三张为普通五。赤五与普通五在组牌、听牌和振听判断中属于同一种牌，在宝牌计数和实际出牌选择中必须保留区别。

每张实体牌必须有唯一编号，避免同一张牌重复出现。牌谱必须记录实际打出的是赤五还是普通五。

### 2.2 座位与庄家

开场由服务器随机确定四人的初始东、南、西、北座位。初始东家先做庄。行牌顺序为当前东家 → 南家 → 西家 → 北家 → 东家。

换庄时，由原庄家的下家成为新庄家，各玩家自风相应改变。初始座位顺序永久保存，仅用于同点排名等规则，不因换庄重写。

### 2.3 信息可见性

公开信息包括场风、局数、本场、供托、点数、自风、牌河、副露、已声明暗杠的牌种、已翻宝牌指示牌、立直状态及牌山剩余张数。

玩家在对局中只能看到自己的暗手牌和摸牌。其他玩家手牌、未来摸牌、未翻指示牌与里宝牌不得提前下发。AI 也只能使用本座位可见的信息。

和牌时公开和牌者手牌；荒牌时公开所有被判定为听牌者的手牌。整场结束后的回放可以显示四家手牌及完整牌山，进行中的牌谱接口不得泄漏这些信息。

## 3. 配牌、牌山与通常回合

### 3.1 配牌

服务器使用适合随机洗牌的安全随机源，对全部 136 张实体牌洗牌。

逻辑上先划出 14 张王牌，其他 122 张作为配牌和通常摸牌区域。四家先各获得 13 张，再由庄家获得首张摸牌。因此庄家首次出牌前有 14 张，其他人 13 张，通常牌山剩余 69 张。

服务器须固定配牌与取牌顺序并写入牌谱；画面上的掷骰、切牌可为表现动画，但不能改变已经确定的牌序。

### 3.2 王牌

王牌包含四张岭上牌，以及五组表／里宝牌指示牌，共 14 张。开局只翻开第一张表宝牌指示牌。

每次成功开杠，从岭上区摸一张补充牌，并将通常牌山末端一张移入王牌的补充区域，使王牌始终保持 14 张。补入的牌不再用于通常摸牌，也不新增岭上摸牌次数。

每个成功的杠增加一组有效指示牌，最多五组；整局最多四个杠。牌谱必须足以还原通常牌山、岭上顺序、补入牌和指示牌。

### 3.3 通常回合

玩家通常摸一张牌，然后选择合法操作：自摸和牌、暗杠、加杠、立直打牌或普通打牌。

出牌后先处理其他三家的响应。没有和牌或鸣牌时，下家继续摸牌。吃或碰成功后，由鸣牌者直接打出一张牌，不额外摸牌；明杠成功后先摸岭上牌，再打牌。

打出后被吃、碰、杠的牌，应从牌河的实体牌展示位置转移至副露区，但原弃牌记录永久保留，并继续参与舍牌振听、流局满贯等判断。

### 3.4 牌数约束

将每个杠作为一个面子、按三张折算，打牌后持有等价 13 张，摸牌或吃碰后待打牌时等价 14 张。实际实体牌数会因杠增加，不能用“实际必须只有 13／14 张”判错。

## 4. 吃、碰、杠与响应裁决

### 4.1 吃与碰

- 吃：仅可吃上家刚打出的牌，以自己两张同花色数牌组成顺子。字牌不能吃，顺子不能跨花色或九一循环。
- 碰：可碰任意一家刚打出的牌，以自己两张同种牌组成刻子。
- 立直成立后不可吃、碰、明杠、加杠。
- 通常牌山已无牌时，最后弃牌只能被荣和，不能再吃、碰或明杠。

### 4.2 食替限制

本项目禁止现物食替及筋食替，仅约束吃／碰后紧接着的那次弃牌：

1. 碰后，不可立即打出同种牌。
2. 吃后，不可立即打出被吃牌同种的牌。
3. 吃后，也不可打出能与本次从暗手中取出的同一对牌组成另一顺子的牌。

例如，用手中的三四万吃二万后，不能立即打二万或五万；用二四万吃三万后，不能立即打三万。赤五与普通五按同种牌处理。

如果某种吃／碰方案会导致紧接着没有合法弃牌，该方案本身就不提供。食替限制不延续到之后的回合。

### 4.3 杠

| 类型 | 条件 | 门清影响 |
| --- | --- | --- |
| 暗杠 | 自己摸牌后的操作阶段持有四张同种牌 | 不破坏门清 |
| 明杠／大明杠 | 别家弃牌，自己持有三张同种牌 | 破坏门清 |
| 加杠／小明杠 | 自己摸牌后的操作阶段，将一张同种手牌加入已有碰面子 | 破坏门清 |

只有通常牌山至少还剩一张、岭上牌尚有剩余、全桌成功杠数少于四时，才可发起杠。吃／碰后的直接弃牌阶段不能连续发起新的暗杠或加杠。

杠的固定顺序：声明候选杠 → 处理可能的抢杠 → 杠正式成立 → 立即翻开新杠宝牌 → 取消一发 → 从岭上摸牌 → 自摸／继续合法杠／打牌。

所有类型的杠均采用“杠成立后、岭上摸牌前立即翻杠宝牌”的时机，不采用明杠延后翻牌。

加杠可以被符合条件的玩家抢杠荣和；暗杠仅允许被国士无双抢杠，不能被其他役种抢杠；大明杠不另开抢杠窗口，原弃牌的荣和本来就优先于明杠。

被抢的杠不算成功杠，不摸岭上、不翻新指示牌，也不因该未成立的杠取消一发。被抢走的一张牌作为和牌牌处理；加杠前的碰保持原状态。

### 4.4 多人响应

每张弃牌先收集相关玩家的响应，再一次性裁决，不能按网络消息到达顺序直接决定胜负。

裁决顺序：合法荣和 → 已触发的强制途中流局 → 碰／明杠 → 吃 → 无操作继续摸牌。

碰与明杠同级；若出现同级竞争，按从出牌者下家开始的行牌顺序优先。每名玩家在一个响应窗口只提交一种最终动作；提交后不能修改。尚未确定裁决前，不公开其他人的响应选择。

- 一家合法荣和：该家和牌。
- 两家合法荣和：双响成立，其他鸣牌作废。
- 三家合法荣和：三家和途中流局，所有和牌结算作废。
- 明确选择过牌或在截止前未响应，都视为本窗口放弃；符合条件时产生振听。

只要还有未响应且可能改变最终裁决的玩家，就应等待其响应或超时。玩家本次看到的按钮必须来自服务器计算的合法动作列表。

## 5. 听牌、和牌与振听

### 5.1 和牌结构

合法完成形限于：

1. 通常形：四面子加一雀头，面子可以包含已声明的杠。
2. 七对子：七种不同牌各两张；四张同种牌不能当作两对。
3. 国士无双：十三种幺九牌各至少一张，其中一种再有一张形成雀头。

七对子和国士必须门清且没有任何杠。满足结构后，还必须有至少一个役。宝牌、赤宝牌、里宝牌仅增加番数，不构成役。

和牌牌可以存在多种拆分与归属。服务器应枚举合法解释，选择实际应收和牌点最高的方案；不得只用第一种拆牌结果。固定本场、供托等不参与拆分优选。

### 5.2 听牌

等价 13 张的牌，在加入一种实际存在的牌种后能够形成上述任一完成形，即为结构听牌。无役或振听不影响荒牌听牌结算。

判断不能要求第五张同种牌：暗手与自己的已声明面子合计已经占用该牌种全部四张时，不能把该牌种算作有效完成牌。仅仅在别家手中、牌河、王牌或公开区域已经看完，不取消听牌资格。

### 5.3 振听

振听只禁止荣和，不禁止有役自摸。

| 类型 | 触发 | 解除 |
| --- | --- | --- |
| 舍牌振听 | 当前全部结构完成牌中，任一牌种出现在自己本局弃牌历史中 | 手牌变化后重新计算；立直后通常无法改变 |
| 同巡振听 | 未立直时，放弃一次本来合法的荣和，包括超时 | 到自己下一次摸牌时解除，岭上摸牌也算；单纯吃／碰不解除 |
| 立直后见逃振听 | 立直成立后放弃一次合法荣和，包括超时 | 本局不解除 |

舍牌振听看的是全部结构完成牌，不是只看这次想荣和的一张，也不是只看其中有役的一张。自己打出后被他人鸣走的牌仍然算自己的弃牌。

未向玩家提供合法荣和的弃牌，不因“没有按荣和”新增同巡／见逃振听；例如该牌虽能凑出结构但无役，或玩家已处于振听。本项目以服务器合法荣和列表为该类触发依据。

允许振听立直。立直后仍可自摸，不能因宝牌或增加番数绕过振听限制。

## 6. 立直、双立直与一发

### 6.1 立直条件

玩家在自己的摸牌后操作阶段，同时满足以下条件，才能选择立直并指定一张弃牌：

- 当前门清，指定弃牌后结构听牌。
- 当前持有至少 1,000 点。
- 此时通常牌山至少剩四张。这里指已完成本次摸牌、尚未打出立直牌的时刻。
- 尚未立直，指定弃牌合法。

本项目选择“至少四张剩余牌才可立直”，不采用允许零张或不足四张仍立直的变体。

### 6.2 成立时机与供托

立直声明牌先作为弃牌进入响应阶段。如果被一家或两家荣和，声明者该次立直不成立，不扣 1,000 点。若该牌导致三家和途中流局，同样不收取这次未成立的立直棒。

无人荣和后，立直成立，扣除 1,000 点进入供托池。声明牌被吃、碰、明杠不取消立直成立，但会取消一发。立直牌在牌河中横放；若被鸣走，须在界面保留立直标记。

四家立直时，第四家的立直棒先在无人荣和后正式收取，再执行四家立直途中流局。

### 6.3 立直后的行动

立直成立后，除合法和牌或满足第 6.4 节条件的暗杠外，只能摸切本次摸到的实体牌。不得换打原手牌、重新选择听牌、取消立直或加杠。

摸到赤五时不能以“同种牌”为由改打手里的普通五，反之亦然。放弃自摸后继续摸切不自动新增“见逃荣和振听”；其原有振听状态照常保留。

### 6.4 立直后暗杠

采用严格条件，全部成立才允许：

1. 本次摸到的牌是将要暗杠的第四张，原锁定暗手中已有该种牌的三张。
2. 杠前后的结构完成牌集合完全一致。
3. 对每一种完成牌与每一种合法完成拆分，原来的三张始终作为同一个完整刻子存在；不能把它们用于顺子、雀头或作为其他拆分的一部分。
4. 将该固定刻子替换为杠后，各完成拆分的其余面子及和牌牌归属保持对应，不新增或删除解释。
5. 满足通常开杠的牌山与杠数限制。

不能仅比较“向听数没变”或“听牌种类没变”。役种或符数因固定暗刻升级暗杠而发生变化，本身不构成禁止理由。暗杠成功会取消一发。

### 6.5 双立直与一发

双立直：玩家在自己的第一次弃牌时立直，且从开局到此次声明前，没有发生任何成功的吃、碰、杠（含暗杠）。双立直计两番，替代普通立直，不叠加成三番。

一发：立直声明之后，直到立直者下一次摸牌后的弃牌前，有效自摸或荣和可加一番。立直者下一次摸牌后若选择打牌，一发窗口随该次弃牌产生而结束；别人荣和这张牌与立直者自己无关。

任何玩家在窗口内成功吃、碰或杠（含暗杠）都会取消一发。原弃牌同时存在和牌与鸣牌时先判和牌，未成立的鸣牌不取消一发；抢加杠可在其他条件满足时与一发复合。

## 7. 宝牌与特殊摸牌情境

### 7.1 宝牌指示关系

- 数牌：同花色下一数字为宝牌，九之后回到一。
- 风牌：东 → 南 → 西 → 北 → 东。
- 三元牌：白 → 发 → 中 → 白。

和牌者手牌、雀头、顺子、刻子、杠中，每一张对应宝牌均加一番，杠的四张全部计入。同种宝牌被多张指示牌指示时，重复累计。赤五每张额外加一番，可同时计表宝牌和里宝牌。

只有已成立立直的和牌者使用里宝牌；有效里指示牌数量与当时有效表指示牌数量相同，包括杠里宝牌。双响时，各和牌者分别按其立直状态判定。

### 7.2 海底、河底、岭上与抢杠

- 海底摸月：从通常牌山摸走最后一张并自摸。必须是通常摸牌，岭上摸牌不能算海底。
- 河底捞鱼：通常牌山已空时，对最终弃牌荣和。若最后一次摸牌是岭上牌，随后弃牌使牌局结束，该弃牌也可成立河底。
- 岭上开花：杠成功后直接摸到的岭上牌自摸。可与门前清自摸和复合，但不与海底复合。
- 抢杠：抢合法的加杠荣和，计一番；本项目允许的国士抢暗杠按国士役满处理。抢杠不与河底复合。

## 9. 符数与和牌点

### 9.1 符数

普通形基础 20 符，按下表加符，最后向上取整至十位。先应用特殊固定符规则，再应用一般累加规则。

| 项目 | 符数 |
| --- | ---: |
| 门清荣和 | +10 |
| 自摸 | +2，平和自摸例外 |
| 中张明刻 | +2 |
| 中张暗刻 | +4 |
| 幺九明刻 | +4 |
| 幺九暗刻 | +8 |
| 中张明杠／加杠 | +8 |
| 中张暗杠 | +16 |
| 幺九明杠／加杠 | +16 |
| 幺九暗杠 | +32 |
| 三元牌雀头 | +2 |
| 自风雀头 | +2 |
| 场风雀头 | +2，与自风重合时共 +4 |
| 单骑、嵌张、边张 | +2，一次和牌解释至多加一项听牌符 |

边张只指 12 等 3、89 等 7；23 等 1 或 4 是两面。双碰不加听牌符，但荣和补齐的刻子按明刻加符，并且不能计入三暗刻／四暗刻的暗刻数量；其余门清属性不受影响。

特殊规则：

- 平和自摸固定 20 符，不加自摸两符；平和荣和固定 30 符。
- 七对子固定 25 符，不加其他符，也不进位到 30。
- 副露普通形如果荣和时累加结果恰为 20 符，按 30 符计算。
- 岭上自摸照常加自摸两符；有杠时不能成立平和。
- 役满不计算用于支付的符数。

### 9.2 基本点与上限

未满贯的普通和牌基本点：`B = 符 × 2^(番 + 2)`。

| 条件 | 基本点 B |
| --- | ---: |
| 1～4 番，公式结果小于 2,000 | 使用公式结果 |
| 1～4 番公式结果至少 2,000，或 5 番 | 满贯 2,000 |
| 6～7 番 | 跳满 3,000 |
| 8～10 番 | 倍满 4,000 |
| 11～12 番 | 三倍满 6,000 |
| 普通役与宝牌合计至少 13 番 | 累计役满 8,000，封顶一倍 |
| 天然役满 n 倍 | 8,000 × n |

不切上满贯，因此 4 番 30 符、3 番 60 符基本点均为 1,920。

### 9.3 支付与进位

以下每个独立付款金额均向上进位到 100 点，不能先把未进位的多人付款相加再进位：

| 和牌者／方式 | 基础支付 |

| 子家荣和 | 放铳者支付 `4B` |
| 庄家荣和 | 放铳者支付 `6B` |
| 子家自摸 | 庄家支付 `2B`，另两子家各支付 `B` |
| 庄家自摸 | 三名子家各支付 `2B` |

其中 `ceil100(x) = 100 × ceil(x / 100)`。子家荣和使用 `ceil100(4B)`，庄家荣和使用 `ceil100(6B)`；自摸按表中公式分别进位。

每一本场，荣和时放铳者额外支付 300 点；自摸时其他三家各额外支付 100 点。本场不是实际筹码池，不能从点数总和中凭空扣除或增加。

双响时，放铳者分别向两家支付各自的完整和牌金额及各自的本场 300 点。供托不重复发放，由从放铳者下家开始按行牌顺序最靠前的和牌者一次领完。

## 10. 责任支付（包牌）

本项目只对大三元和大四喜设置包牌，不设置四杠子包牌或大明杠岭上包牌。

当某玩家已经公开两组三元刻／杠，又由另一玩家供牌使其碰／明杠完成第三组三元刻／杠，供牌者成为其大三元责任者。大四喜同理，在已经公开三组风刻／杠时，供出第四组者负责。此前的加杠仍视为原碰的公开信息；暗刻、暗杠不作为这里的“已经公开刻／杠”触发前提。

仅当最终确实和出对应役满时才执行责任支付：

- 自摸：责任者承担该项役满的全部基础付款总额。
- 荣和且放铳者就是责任者：责任者承担该项役满全部基础金额。
- 荣和且放铳者不是责任者：责任者与放铳者各承担该项役满基础金额的一半。
- 复合役满：只对有责任关系的那一项使用包牌，其他役满按正常方式支付。

本场另外处理：荣和由放铳者支付全部本场；自摸存在包牌时，由责任者支付全部本场。供托仍按通常规则发放。一个完成形不可能同时拥有大三元和大四喜，因此这里不存在两名不同责任者争议。

例：子家和出“大三元＋字一色”两倍役满，A 为大三元责任者，B 为放铳者且 A≠B：大三元 32,000 由 A、B 各付 16,000，字一色 32,000 由 B 独付；合计 A 付 16,000、B 付 48,000，另由 B 支付本场。

## 11. 荒牌与途中流局

### 11.1 荒牌流局

通常牌山摸完后，最后弃牌无人荣和，先检查流局满贯；没有流局满贯时才进行普通荒牌结算。

由服务器自动判定所有玩家结构听牌，不允许玩家通过隐藏手牌选择不报听牌。听牌者向未听者收取合计 3,000 点罚符：

| 听牌人数 | 点数移动 |
| ---: | --- |
| 0 或 4 | 无 |
| 1 | 三名未听者各付 1,000，听牌者共收 3,000 |
| 2 | 两名未听者各付 1,500，两名听牌者各收 1,500 |
| 3 | 未听者付 3,000，三名听牌者各收 1,000 |

庄家听牌则连庄，未听则换庄。无论是否换庄，本场加一，供托保留。无役听牌、振听听牌均有效，只有违反“不能需要第五张同种牌”等结构条件才判未听。

### 11.2 途中流局

途中流局不结算听牌罚符，庄家不变，本场加一，既有供托保留。

| 类型 | 触发与时机 |
| --- | --- |
| 九种九牌 | 玩家第一次摸牌后的操作阶段、尚未首次弃牌，且此前无任何成功吃碰杠；持有至少九种不同幺九牌时可主动选择流局；不是自动触发 |
| 四风连打 | 四家第一次弃牌全部是同一种风牌，期间无成功吃碰杠；第四张先处理荣和，无荣和则流局，不再接受对这张牌的鸣牌 |
| 四家立直 | 四家立直均成立；第四张声明牌先处理荣和，收取成立的第四根立直棒后流局 |
| 四杠散了 | 第四个杠成功成立且四个杠不全属于同一人；允许第四次岭上自摸，未和则在其后弃牌的荣和响应结束后流局，不再接受鸣牌 |
| 三家和 | 对同一弃牌或可抢杠牌，三家均有效声明荣和；直接流局，优先于和牌计分 |

四杠全由同一玩家完成时不流局，继续进行，允许四杠子和牌，但禁止第五个杠。

四杠散了的待流局弃牌若同时有一家或两家荣和，按和牌结算；若有三家荣和，则按三家和流局。第四杠若被抢，根本未成功成立，不触发四杠散了。

这些触发条件遇到和牌时，除三家和本身外均以有效和牌优先。普通荒牌结算在强制途中流局之后，不能同时结两种流局。

## 12. 流局满贯

本项目将流局满贯作为荒牌时的特殊和牌结算，不作为普通荒牌听牌支付。

满足以下全部条件者成立：本局至少有一次弃牌，自己的所有弃牌均为幺九牌，自己的任何弃牌均未被他人吃／碰／明杠，且自己没有任何已声明面子（包括暗杠）。不要求听牌或门清役，不因立直状态取消资格。

其他玩家的鸣牌不直接取消资格，除非鸣走了自己的弃牌。只在正常荒牌时检查，途中流局或已有通常和牌时不能成立。

- 单家成立：按该家自摸满贯结算，附加通常本场并领取全部供托。
- 多家成立：每家都按一次自摸满贯分别计算点数移动，包括成立者之间的相互支付；最终把全部移动相加。
- 多家成立时，供托只给按本局东 → 南 → 西 → 北顺序最靠前的成立者，不重复发放。
- 不结算听牌罚符；成立者中有庄家则连庄、本场加一，否则换庄、本场归零。

此处“多家相互支付、无任何暗杠、视为和牌连庄”均为本项目明确选择的变体约定，不能直接沿用其他平台的默认实现。

## 13. 连庄、本场、供托与终局

### 13.1 单局结束的统一处理顺序

1. 确定结果类型，不能同时算和牌与流局。
2. 处理本次尚未成立立直的扣款／不扣款；四家立直按专门规则处理。
3. 一次性计算全部和牌、包牌、本场、罚符和供托移动，再原子更新点数；双响不得在第一家结完时就提前判断飞人。
4. 得到本次结算后的名次。名次同分时用初始座位优先。
5. 按第 13.3 节判断是否终局。
6. 未终局时才按第 13.2 节更新庄家、局数与本场，开始新局。

### 13.2 下一局

| 结果 | 庄家 | 本场 | 供托 |
| --- | --- | --- | --- |
| 普通和牌／流局满贯，和牌者中有庄家 | 连庄 | +1 | 按和牌规则发放后清空 |
| 普通和牌／流局满贯，和牌者中无庄家 | 换庄 | 归零 | 按和牌规则发放后清空 |
| 普通荒牌，庄家听牌 | 连庄 | +1 | 保留 |
| 普通荒牌，庄家未听 | 换庄 | +1 | 保留 |
| 途中流局 | 连庄 | +1 | 保留 |

连庄不改变当前局号。每次换庄将局号加一，四局后切换场风。首局为东一局零本场、零供托。

### 13.3 终局算法

**共同规则**：所有判断均在单局全部结算完成后进行。若任一玩家点数小于 0，立即飞人终局；恰好 0 不终局。首版没有整场倒计时强制结算。

**计划范围**：东风战为东一至东四，半庄战为东一至南四。计划范围的最后一局分别为东四、南四，连庄仍属于同一最后计划局。

在最后计划局结算后：

1. 若庄家和牌（含流局满贯），或普通荒牌且庄家听牌，同时庄家排名第一且至少 30,000 点，自动终局。不给玩家选择继续连庄。
2. 否则，若本次结果应连庄，继续当前局；即使另一家已经 30,000 点也不因此提前结束。
3. 否则，本次应换庄：任一玩家达到 30,000 点就终局；无人达到则进入延长场。
4. 途中流局不触发和了止或听牌止，除飞人外继续当前局。

在此前的非最后计划局中，达到 30,000 点不提前终局，正常继续计划赛程。

**延长场**：东风战延长到南场，半庄战延长到西场。进入延长场后：

1. 每次结算只要任一玩家至少 30,000 点，立即终局，不要求换庄，不要求庄家第一。
2. 若均未达到目标，按通常规则连庄或换庄。
3. 延长场第四局采用硬上限：南四／西四第一次完成单局结算后即终局，即使庄家应连庄或结果为途中流局，也不再重开该局。此项是本项目为限制延长范围作出的明确选择。

### 13.4 最终供托、排名与成绩

若整场结束时仍有供托，先按“发放前点数、同分初始座位优先”确定第一名，再将全部剩余供托发给该玩家，最后形成最终点数和名次。该发放仅用于清算，不会使已经结束的比赛重新继续。

首版不使用马点、返还点与头名赏。成绩记录：最终点数、`最终点数 - 25,000` 的净得失、最终名次、赛制与规则版本。

整场进行中应始终满足：`四家点数之和 + 供托池点数 = 100,000`。整场最终供托清零后，四家最终点数之和必须为 100,000。本场是计数器，不加入此守恒式。


## 开桌与入座

留个名字就能以游客入座，不必注册；关掉页面再回来，座位还在。点“开一桌”后，把邀请链接或 6 位邀请码发给朋友，对方点开便入座。少一个人，房主可在空位上“请 AI 入座”：先在按钮旁选好档位，入座后也能随时改。

AI 分四档，座位上和牌桌的名牌下都写着它的档位：

| 档位 | 打法 |
| --- | --- |
| 初级 | 只看手牌离听牌还差几步，能立直就立直，能鸣就鸣；别人立直也照打不误。适合熟悉操作。 |
| 中级 | 会数场上还剩几张有用的牌；有人立直时切现物弃和；最后一局领先时不再立直。 |
| 高级 | 没有现物时会看筋和字牌的剩余张数；手牌够大、够快才对攻，否则弃和；留宝牌，满贯以上默听，不为便宜的断幺拆掉快听的门前手。 |
| 大师级 | 每一张牌都把“和牌的机会 × 打点”与“放铳的机会 × 损失”放在一起比；记得立直后通过的牌、会读壁，也提防副露两副以上的对手；副露时只走还有役的路线。 |

四档遵守同一套规则，只看得到自己座位能看到的牌，不靠随机失误来区分强弱。

牌桌由房主选东风战或半庄战。众人准备后，由房主开局，座位随机分定。换人、改赛制或调 AI 档位后，需要重新准备。开场时只有你一位真人，这场就算 AI 练习；有两位以上真人，算好友场。

半庄战计划打到南四，必要时延长至西四；东风战最多延长至南四。连庄、击飞和提前终局都会改变局数，所以一场的时长并不固定。

## 对局中

出牌限时 15 秒，吃碰杠与荣和的应答 8 秒。AI 出手前会留约 2 秒，鸣牌约停 1.2 秒，方便看清。

轮到你时，选一张牌再点“打出”。牌桌下方有三个开关：

- **快速出牌**：点一下就打出，不再确认；立直时仍要先选牌。这一项会记在本机。
- **自动摸切**：摸到什么打什么；能和、能杠时停下等你。
- **不鸣牌**：他家打牌不吃、不碰、不杠；能荣和时仍会停下。

后两项只在这一场有效，离开页面或牌桌有变时会自动关闭；想临时自己来，点“这一手我来”。

键盘随时可用，不必先点牌桌：← → 选牌，Enter 打出；R 立直，C 吃，P 碰，K 杠，W 和，空格过，Esc 取消。在输入框里打字时不会触发。

吃、碰或明杠时，会先列出来源牌、要用的手牌和组成后的面子，选好再确认。被别家更优先的操作抢先时，未成立的鸣牌不会动你的手牌。放过一张能荣和的牌，会先问一句“这张能荣和，确定要过？”。

横屏时默认是 3D 牌桌，可随时换成平面牌桌；设备吃力或不支持时会自动换成平面。动画跟随系统的“减弱动态效果”设置。

掉线不会让牌局停下，期间由 AI 托管，重连后即可接着打。也可以主动“交给 AI 托管”，再“收回托管”。托管一律由中级 AI 代打，名牌下会写“中级 AI 托管中”。一手出牌没有回音时，页面会自动确认，不必重复出牌。

## 一场之后

打完一场，房主可以“再来一场”：邀请码和成员不变，大家重新准备，重新分座，各从 25,000 点开始。等待再来一场时，离线超过 30 秒的真人会被请离座位。意外中止的对局不计入战绩，再开一桌即可。

“战绩”页列出你打过的每一场，可按赛制和场次（好友场、AI 练习）筛选。页首是近 30 天的小结：场数、一位率、平均顺位、平均得失和各名次的场数，只算正常打完的对局。

点开一场能看每一局的点数变化，也能看牌谱：按步播放，切换视角，或亮出四家手牌和本局牌山。“本局要点”可直接跳到立直、鸣牌、杠、和牌与流局。下次打开会回到上次看到的地方。牌谱只对同桌的人开放，至少保存 30 天。

## 账号与好友

游客的战绩跟着这台设备。注册后，换台设备也能接着打，已有战绩一并带上。登录另一个已有账号时，当前游客的战绩不会合并过去。

账号可以改名字（每 24 小时一次），选 12 款预设头像，或上传 PNG、JPEG、WebP 照片（不超过 5MB）做头像；在房间或对局中时暂不能改。过去的牌谱里仍是当时的名字和头像。需要时，可以凭当前密码“退出其他设备”，那边若正在打牌，会转为 AI 托管。

每个账号有一个 12 位好友码，和 6 位房间邀请码不是一回事。输入朋友的好友码就能申请，对方同意后成为好友；申请 7 天内有效。“待处理”里集中放着别人的入座邀请、好友申请和你发出的申请。房主可在牌桌上“邀请好友”，邀请 5 分钟内有效，不占座位。

在线状态只有好友看得到，好友也看不到你的战绩和牌谱。解除好友是双向的。屏蔽后对方不能再加你或邀请你，但仍能用房间邀请码同桌；解除屏蔽不会恢复原来的好友关系。

预览站的账号和战绩与正式站互不相通。
