## 实现范围

- 个人入口区分游客与账号；当前游客注册保留 userId、历史、排名和观看位置，登录其他账号不合并游客记录；退出返回未登录首页。
- REGISTER／RESET_PASSWORD 六位安全均匀随机码，十分钟截止、六十秒跨用途冷却、单挑战五次和十五分钟滚动累计限制；用途、环境、流程和原注册会话绑定。完成凭据 32 字节随机、五分钟、单次消费，重试不延长授权。
- Argon2id 异步密码计算（19,456 KiB／t=2／p=1），最多两个活动任务及有界队列；密码原样处理空格，按 Unicode 码点限制长度。无效完成凭据先拒绝，幂等回执重放不再哈希；哈希后事务再次校验截止及消费状态。
- 三十天哈希会话及 authVersion；注册／登录／改密轮换，普通退出仅撤销当前设备，找回撤销全部旧会话且不自动登录，改密仅保留新当前会话。HTTP／Socket 排队执行和私有推送重新校验身份。
- 本机身份变更先明确托管释放；远端找回保留原座位、点数和已提交动作。客户端身份代际隔离旧连接回调。
- 同事务记录挑战、幂等回执与 AES-GCM 加密发信任务；SMTP 网络与哈希不占麻将裁决队列。最多三次实际尝试、同码同截止、终态清除正文密文，重启回收租约。TLS 465 验证证书、预览白名单和标记、跨环境共享发信预算。
- 邮箱／IP／登录等持久滚动限流；不确定提交后重读权威会话，失败则关闭认证。SQLite／PostgreSQL 统一迁移、环境防误接、唯一性及重跑保护。
- 服务端时间加单调时钟计算验证码倒计时；邀请码在注册／登录期间保留，返回后入房成功才移除。正式注册提示不误用预览文案。
- 配置生成、离线迁移、SMTP 仅认证及恢复副本验证工具；关闭新注册／邮件入口不会把已有账号降级。恢复验证工具只接受专用恢复库名称，不能误跑正式库。

实现入口：`backend/src/auth/`、`backend/src/server.ts`、`backend/src/store.ts`、`frontend/src/account.tsx`、`frontend/src/main.tsx`。参见 [账号与邮件接口](账号与邮件接口-v3.0.md)、[账号配置与运维](账号配置与运维-v3.0.md)。

## 认证负载、资源限制与首轮失败

首轮把服务和发生器都放在共享 2 核／1.87 GiB ECS，内存预算估计过高，触发宿主 OOM，测试进程及 astrbot、napcat 被终止。测试已停止，两项服务自动恢复并逐项确认 active，麻将正式与预览健康正常。首轮还因请求共用一个 IP 达到原有 600 次／分钟限制返回 429；保留 `reports/v3-capacity-initial-failed.json`，未计通过，未放宽正式限流。

修正后发生器移至 Mac，云端仅运行隔离库服务：MemoryMax=320 MiB、MemoryHigh=256 MiB、Node 堆 112 MiB、OOMScoreAdjust=1000，启动要求宿主可用内存至少 450 MiB，低于 200 MiB 自动停止。临时 HTTPS 通道使用随机令牌，测试客户端使用独立 TEST-NET 地址；正常站点的来源地址及限流不变。测试后路由、云端及本机临时凭据移除，18032 端口关闭，原四项服务健康；受限运行期间新增宿主 OOM=0。
