# 等级分规则

2026-11-19 新增。代码：`shared/rating.ts`（公式，前后端共用）、`backend/src/rating.ts`（结算）、`backend/migrations/006_ratings_v43.sql`（表结构）。

每位玩家有一个等级分（整数）。一切正常终局的对局，不论对手是朋友还是假想妖、东风战还是半庄战，都按位次和最终点数加减等级分；对手越强，赢了加得越多，输了扣得越少。分数对应一尾到十尾十个档位。

## 1. 档位

| 尾数 | 等级分 |
| --- | --- |
| 一尾 | 1000 以下（新玩家从 900 起步） |
| 二尾 | 1000–1199 |
| 三尾 | 1200–1399 |
| 四尾 | 1400–1599 |
| 五尾 | 1600–1799 |
| 六尾 | 1800–1999 |
| 七尾 | 2000–2199 |
| 八尾 | 2200–2399 |
| 九尾 | 2400–2599 |
| 十尾 | 2600 及以上 |

等级分最低为 0，没有上限。

## 2. 假想妖的固定分

假想妖的四个档位各有一个固定等级分，正好落在同名尾数档的中间。假想妖的分不会因为输赢变动。

| 档位 | 代码 | 固定等级分 |
| --- | --- | --- |
| 一尾假想妖 | BASIC | 900 |
| 三尾假想妖 | STANDARD | 1300 |
| 六尾假想妖 | ADVANCED | 1900 |
| 九尾假想妖 | MASTER | 2500 |

## 3. 每场的加减

记自己的等级分为 R，另外三家为 R₁、R₂、R₃（真人用其开局时的当前分，假想妖用固定分）。

**位次部分（逐对比较，Elo 式期望）**

对每一家对手 j：

- 实际结果 S = 名次在对方之前记 1，在之后记 0（名次不会并列，同点按开局座位顺序排）。
- 期望 E = 1 / (1 + 10^((Rⱼ − R) / 400))，分差超过 400 按 400 计。

位次部分 = 60 × Σ(S − E) / 3。

四家同分时，一位到四位分别为 +30、+10、−10、−30。对手越强，E 越小：赢了加得更多，输了扣得更少。例：900 分的玩家对上三个 1300 分以上的对手，拿一位约 +55，吃四位约 −5；反过来对三家弱 400 分的对手，一位约 +5，四位约 −55。

**点数部分**

点数部分 = (最终点数 − 25000) / 2000，上下限 ±10。即每多 2000 点加 1 分，45000 点及以上封顶 +10，5000 点及以下封底 −10（被飞也按 −10）。

**合计**

本场加减 = 四舍五入[(位次部分 + 点数部分) × 赛制倍数]

- 东风战倍数 1，半庄战倍数 1.5。
- 结算后低于 0 的按 0 计。

四家都是真人且分数相同时，整桌的加减之和为 0。

## 4. 特殊情况

| 情况 | 处理 |
| --- | --- |
| 和假想妖打 | 照常计分，假想妖按固定分参与期望计算，自己不变动 |
| 游客 | 和账号一样计分，分数挂在游客身份上；注册时身份保留，分数一并保留 |
| 托管、中途暂离 | 这个座位仍算本人：用本人的分参与计算，结果计入本人。托管的假想妖只是代打 |
| 流局（荒牌、途中流局） | 只是其中一局，不影响整场；整场正常终局就照常结算 |
| 意外中止（ABORTED） | 不计分，也不计入战绩 |
| 新玩家 | 初始 900 分（一尾） |
| 上线前的旧对局 | 不补算，所有人从初始分开始 |

## 5. 结算的实现

- 对局正常终局（`status = FINISHED`）时，服务端用各家当前分算出本场的加减，写进对局结果 `matchResult.ratingChanges`，之后每次保存、视图和重启都沿用这组数字。
- 结算与对局、战绩写在同一个数据库事务里。`rating_settlements` 以 `match_id` 为主键，是幂等键：重复保存、重试或重启后重放都只结算一次。
- 表：`player_ratings`（当前分与已结算场数）、`rating_settlements`（已结算的对局）、`rating_changes`（每人每场的前后分和加减）。SQLite 与 PostgreSQL 共用同一份定义，启动时幂等建表。
- 接口：`/api/me` 返回 `rating`；房间座位 `Member.rating`、牌桌 `PublicPlayer.rating`（开局时的分）；战绩 `HistoryMember.rating` 与结算 `MatchResult.ratingChanges`（`before`、`after`、`delta`、`fixed`）。

## 6. 界面

- 牌桌名牌：真人名字后显示尾数，悬停可见数值。
- 牌桌（房间）座位：真人显示尾数和数值，如“一尾 900”。假想妖照旧写“假想妖，三尾”。
- 账号页：“等级分 938，一尾”。
- 一场终了：每家一列尾数和本场加减；下面一句给自己，如“等级分 +38，现在 938，一尾”，跨档时写“升到二尾”或“回到一尾”。
- 战绩：列表里每场带上本场加减，详情里每位真人显示尾数和加减。

## 7. 可调参数

都在 `shared/rating.ts`：初始分 900、K = 60、分差上限 400、每 2000 点 1 分、点数修正 ±10、半庄倍数 1.5、档位每 200 分一档。改动后旧的结算不重算。
