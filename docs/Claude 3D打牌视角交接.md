## 用户目标

将现有网页麻将的对局画面改为**类似雀魂的 3D 打牌视角**，接入现有真实对局。

用户目前只提出了这个方向，未确定具体画面、技术路线或实现细节。本交接不提供设计方案，不预设渲染框架、镜头参数、模型、材质、动画或操作区布局。“类似雀魂”是视角参考，不代表要求复制其全套界面或素材。

## 当前基础

- 源码版本 `0.4.2`；React 19 + TypeScript + Vite，普通 CSS；后端 Express + Socket.IO。
- 当前牌桌为 DOM／SVG／CSS 展示，`package.json` 尚无 3D 渲染依赖。
- 已有四人立直麻将、AI、联机同步、断线恢复、结算和回放。此次工作围绕对局展示，不扩展为全站重做。
- **工作区有大量未提交的界面修改**，包括牌桌组件、全局样式以及新增的 `tokens.css`、`base.css` 和 `DESIGN.md`。开始前检查当前差异并保留已有成果，不回退或覆盖。
- `docs/Claude页面美化交接.md` 是较早的全站美化交接；其中的视觉描述可能已过时，不作为此次 3D 任务的设计要求。当前样式背景可查 `DESIGN.md` 和 `frontend/src/tokens.css`。

## 改造必须保留

- 对局展示使用服务端下发的真实视图；规则裁决和合法行动仍由现有系统负责，不另写一套对局状态机。
- 所有出牌和吃碰杠等动作继续经过统一控制器，保留授权检查、提交锁、断线同步和回执未知时的恢复流程。
- 保留普通选牌后确认、立直确认、放弃荣和确认，以及快速出牌／自动摸切／不鸣牌／键盘操作现有语义；四项开关默认关闭。
- 牌按 **0–135 的实体 ID** 区分，不能按牌种合并；保留赤牌、独立摸牌、鸣牌来源、杠、立直横牌、摸切和最新弃牌等信息。
- 以 `viewerSeat` 确定本人及其他座位；他家暗手只按可见数量显示牌背，不暴露隐藏牌。
- 保留局况、宝牌指示、点数、倒计时、连接／托管状态、特殊行动、局结算和整场结算；后期多行牌河及多组副露也要可用。
- 展示结构变化时同步核对指针、键盘、焦点、弹窗和禁用状态，避免误出牌或重复提交。
- 保持现有子路径部署兼容；新增素材说明来源与许可。此次不涉及线上部署、数据库迁移或真实凭据。

## 本地运行与交付

需要 Node.js 24.7+、pnpm 11+。安装依赖后，分两个终端启动，使用独立本地数据库：

```sh
pnpm install --frozen-lockfile
NODE_ENV=development DATABASE_URL= SQLITE_PATH=data/3d-preview/mahjong.sqlite SESSION_COOKIE_NAME=mj_3d_preview_session PUBLIC_ORIGIN=http://127.0.0.1:5173 pnpm dev
```

```sh
pnpm dev:ui
```

访问 `http://127.0.0.1:5173`；后端端口为 3000。若已占用，先检查现有服务。不要删除原有 `data/` 来重置页面。

改造完成后运行 `pnpm build` 和 `pnpm test`，实际检查真实对局操作、特殊行动、后期牌面、断线恢复及不同屏幕尺寸。已有 `pnpm test:table:browser` 可供参考；若展示结构改变，需核对其选择器与断言是否仍有效。

交付本地可运行结果、截图或预览，以及实际验证结果和未验证项。不能将静态演示或历史测试记录当作此次改造已完成的证据。

本次交接只核对了本地源码与文档，没有修改功能、重新运行测试或检查线上状态。
