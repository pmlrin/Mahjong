## 1. 实现

| 能力 | 最终行为 |
| --- | --- |
| 快速出牌 | 默认关闭；主指针完整点击才提交精确实体 `DISCARD`；移动超过 8 CSS 像素、跨牌、取消、多指、滚动、失焦及失效决策均不提交；键盘和读屏激活仍只选牌。立直始终选牌后明确确认。 |
| 自动摸切 | 默认关闭；仅合法 HUMAN 的 AFTER_DRAW 窗口，按 `drawnTile` 精确实体等待 500 毫秒；自摸、暗杠、加杠、九种九牌、手动介入或弹窗会让出当前决策；剩余不超过 500 毫秒不安排。 |
| 不鸣牌 | 默认关闭；合法响应无 RON 时等待 500 毫秒后提交原 PASS；保留荣和和抢杠荣和。开启时禁用吃、碰、明杠入口，本人暗杠／加杠仍可选择。手动放弃荣和必须确认，默认焦点为取消。 |
| 键盘 | 默认关闭；限定聚焦牌桌／行动弹窗，固定映射；方向键只选牌，Enter 确认，R/C/P/K/W/Space/Escape 分别处理；输入法、输入控件、修饰键隔离，长按和跨窗口重复键拦截，原生按钮只激活一次。 |
| 设置与状态 | 牌桌四个文字开关，独立自动关闭及本次手动入口；设置页可修改快速／键盘偏好；状态条区分等待、需手动、待裁决与恢复。选牌与焦点有不同样式；窄屏换行，键盘选择会滚动到所选牌。 |

快速／键盘偏好按 `location.origin + BASE_URL + userId` 隔离，自动模式不持久化。离桌、失焦、隐藏、断线、身份或 binding 变化、AI 接管、serverEpoch 变化及比赛结束均停止自动模式。正常局间可保留；恢复前台、重连或重新进桌须先安装匹配 syncId 的权威快照。存储不可用时回落关闭，仍可手动玩牌。

## 2. 动作通道与最小修复

- `frontend/src/table-actions.ts`：独立于渲染的候选判断、决策标识、500 毫秒计时与同步提交锁。所有入口共用 `matchId + handId + serverEpoch + windowId + decisionId` 和最新 option 校验；发送前先同步占锁，再保存记录、更新界面和发送。
- `frontend/src/use-table-actions.ts`：浏览器指针手势、键盘、焦点、前后台生命周期、偏好与身份隔离恢复记录。
- `frontend/src/Game.tsx`：从主应用提取牌桌和原有结算展示，复用原 `TableSurface`、实体 Tile 和鸣牌来源／消耗预览。`main.tsx` 保留实际 socket、binding、最新 frame 和当前用户的二次授权检查。
- 原先每个 viewSeq 清空选牌和 pending 的行为已移除。同一决策的新快照保留合法选择、原等待起点和锁。
- 原先失败后直接解锁及查询失败后丢弃恢复记录的行为已修复。回执不明关闭自动模式并保持原 requestId；查询 404 不产生新选择。明确的“查询／恢复原动作”只在权威状态仍授权原逻辑动作时重发同一 requestId，binding 和 lastSeenViewSeq 按现有协议更新。
- 同步证实旧窗口不再有效后才清理旧不确定动作。包括先同步到原窗口、随后服务器才进入新窗口的情形；后者会请求新同步，避免一直锁住新行动。旧身份或已卸载牌桌的异步回调不会修改新牌桌或删掉恢复记录。

未增加麻将动作类型、HTTP 写接口、服务器计时器、数据库表或迁移；没有修改规则引擎和服务器裁决策略。`package.json` 和 `shared/types.ts` 的 APP_VERSION 均为 `0.4.2`。

## 4. 复验

```sh
pnpm test:table
pnpm test
pnpm build
# 需要本机可用的 Playwright 和 Chrome；PLAYWRIGHT_MODULE 可指定现有 Playwright 模块路径。
pnpm test:table:browser
# 预览路径构建到另一个目录，避免覆盖根路径构建。
pnpm exec vite build --config frontend/vite.config.ts --base /preview/ --outDir /tmp/mahjong-v42-preview-dist
```

浏览器验证程序仅在测试 Vite 服务注入 `__v42_fixture` 和 `__v42_frame` 路由，测试夹具不在正式入口或构建包中。不需要改数据库或导入测试牌局到用户数据。普通模式回退为关闭四个开关；它不影响服务器计时或既有 AI 托管。
