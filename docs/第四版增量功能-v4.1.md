# 第四版增量功能 v4.1

2026-11-02。程序版本0.4.1，麻将协议2.0，沿用既有计分与对局规则。

## 个人头像

正式账号可在个人页上传 PNG／JPEG／WebP 原图（不超过5MB、1600万像素），通过预览调整缩放和位置。浏览器裁成256×256 PNG；服务器只接受300KiB以内、256×256、8位非隔行PNG，校验结构、解压边界、CRC，再重新编码，不保留原文件名、EXIF或文本元数据。不接受远程URL、SVG或动画。

沿用资料的会话校验、profileVersion、持久幂等和房间占位限制。上传只修改头像，不消耗昵称24小时冷却。头像ID由服务器随机生成，仅允许选择本人上传的资产；其他玩家通过固定同源图片接口看到头像，不获得账号或邮箱信息。头像图片可公开缓存，不能用于身份认证。

图片存储于双数据库新增的 avatar_assets 表，总表数29，纳入全库备份。旧比赛／牌谱继续引用当时头像，不覆盖旧图片。重复内容在本人范围复用，每小时最多5次、每天20次上传，每账号最多64份；创建超过7天且不被个人资料、房间或比赛引用的旧资产，在后续上传时有界清理。原12款预设头像继续提供。

接口：PUT /api/v2/profile/avatar，Content-Type:image/png，Idempotency-Key:UUID，X-Profile-Version:正整数；返回新avatarId与profileVersion。GET /api/v2/avatars/:avatarId返回不可变PNG。新增005迁移仅增表／索引，不改写原身份、关系或比赛。

## 简明玩法与役种

玩法说明默认展示摸打、吃碰杠、和牌、立直、振听与赛制六条入门说明，以及四面子一雀头的图示；完整详细规则单独展开。

“查看全部役种”一次展示本桌支持的42种役，每项有门清／副露番数、条件和一副实体牌示例，金色标记和牌牌、蓝底标记副露。支持搜索并清空恢复全清单。特殊时机役明确说明立直、首摸、海底或抢杠条件，不把牌形本身当作充分条件。

42副示例逐一由现有计分引擎验证目标役，检查实体牌不超过四张及杠的等价牌数。流局满贯另列示例牌河，明确它不是固定和牌手牌；宝牌、里宝牌和赤宝牌另作加番说明。本桌不采用的人和及地方役不伪装为已支持。

## 验证范围

覆盖图片伪装、损坏、动画、解压边界与元数据清理；上传权限、他人资产、版本冲突、重复请求、事务回滚、房间占位及旧牌谱冻结；42役完整性与示例计分；桌面及窄屏实际页面。真机结果按实际设备记录，不用窗口模拟冒充真机。
